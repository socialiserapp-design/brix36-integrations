# Brix36 plugin for Cursor

Make a film, music video, picture or motion graphics with your Brix36 account, from Cursor. You see the credit price and approve once before anything is charged. There is no subscription.

## What it adds

- The Brix36 MCP server at `https://api.brix36.com/mcp`, in `mcp.json`. Cursor opens the Brix36 sign-in page the first time a Brix36 tool runs. No token or key goes in this plugin.
- Three skills that walk the agent through pricing, one approval and safe retries: `make-a-film-or-music-video`, `make-a-picture` and `make-motion-graphics`.

## What you need

A Brix36 account. New work uses that account's credits. Finding, playing and downloading your finished videos costs nothing.
